# 数据格式（Data Format）

`bar-chart-race` 接受任意 CSV，长表 / 宽表自动识别。本文档给出规范、列名别名表
与内置数据集的授权说明。

## 1. 两种表结构

### 长表（一行一条观测，最通用）

```csv
date,name,category,value
2000-01-01,Coca-Cola,Beverages,72537
2000-01-01,Microsoft,Technology,70196
```

### 宽表（一行一个参赛者，Flourish 风格）

```csv
name,2018,2019,2020
广东,1559,1780,2293
江苏,1294,1402,1604
```

宽表的表头（除第一列名称外）被解析为时间轴，值为对应年份数值。

## 2. 列名自动识别（中英文别名）

| 语义 | 识别的列名（不区分大小写） |
|---|---|
| 时间轴 | `date` / `时间` / `年份` / `年` |
| 条目名 | `name` / `名称` / `省份` / `国家` |
| 数值 | `value` / `数值` / `GDP` / `val` |
| 分类 | `category` / `分类` / `国家` / `类型` |
| 图标（可选） | `icon` / `image` / `图标` |

- 缺失值记 `0`
- 同一 `(日期, 名字)` 重复出现时取**较大值**
- 可直接把 Flourish 导出的 CSV 拖进页面

## 3. 日期格式

支持以下写法，内部归一为时间轴：

- `2023`
- `2023-01`
- `2023-01-01`
- `2023Q1`
- `2023年3月`

## 4. 柱头徽标（icon 列）

加一列 `icon`，值为 emoji 或图片 URL：

```csv
date,name,category,value,icon
2023,腾讯,科技,99999,🐧
```

不加 `icon` 列时，按分类 / 国家映射、名称关键词、首字圆牌依次降级。

## 5. 模板

页面顶栏「📄 模板下载」提供三份可直接套用的模板（`src/core/templates.js`）：

| 模板 | 结构 | 适用 |
|---|---|---|
| 长表 · 城市人口 | `date,name,category,value` | 通用 |
| 宽表 · 省份年度数据 | `名称,2018,2019,…` | Flourish 风格 |
| 带图标 · icon 列 | 长表 + `icon` | 自定义徽标 |

模板带 BOM 头，Excel / WPS 双击打开中文不乱码。

## 6. 内置数据集与授权

`data/` 下的数据集**仅用于演示**，如用于生产 / 分发请遵循各自来源的许可：

| 文件 | 内容 | 来源 | 授权提示 |
|---|---|---|---|
| `data/category-brands.csv` | 全球最具价值品牌（长表） | Interbrand 品牌价值榜单 | 演示用途；商业使用请取得 Interbrand 授权 |
| `data/cities.csv` | 历史城市人口（宽表） | Chandler (1987) 与 UN (2018) 人口估计 | 学术 / 演示用途；引用请注明来源 |

> 提交新的内置数据集前，请在 PR 中说明来源与授权，并补充到上表。
> 用户上传的私有 CSV 不会被项目采集。
